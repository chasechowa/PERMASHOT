默认矩形模式，半透明蓝色取景框悬浮于屏幕内容之上，下方区域清晰可见。控制栏深色一体化，所有控件一排到底。

  • 零 Canvas 开销，毫秒级保存
  • 自动匹配显示器缩放因子，物理像素级精度
⭕
异形截图

圆形 / 椭圆 / 三角 · 一键切换

四个形状按钮即时切换取景框外形，CSS clip-path 实时预览。截图时 Canvas 遮罩处理，非形状区域输出透明像素。

  • 圆形：Canvas arc(50%, 50%, min(w,h)/2) clip
  • 椭圆：Canvas ellipse(50%, 50%, w/2, h/2) clip
  • 三角：Canvas moveTo + lineTo + closePath clip
  • 输出 PNG 带透明通道，可直接叠加使用
🖱
自由缩放

8 向拖拽手柄 · 精确取景

四角 + 四边中点共 8 个白色拖拽手柄。W / N 方向拖拽时自动平移窗口位置，保持对边屏幕坐标不变。

  • 8 个方向光标 (nw / n / ne / e / se / s / sw / w)
  • 最小限制 50×50px，W×H 输入框双向同步
  • 窗口宽度下限 560px 保证导航栏按钮不挤压
